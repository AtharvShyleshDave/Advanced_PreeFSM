ESP32 / STORAGE DIARY
Embedded project · Offline-first

Your notes.
On your own device.

A compact diary built with an ESP32, an ST7735 TFT display, three physical buttons, and LittleFS internal flash. Write entries from a phone or laptop through a local web page, even without an internet connection.

Built for a small, self-contained diary

Local web editor

Connect to the ESP32's Wi-Fi access point and write entries in a browser. No cloud account or router is required.

Internal flash storage

LittleFS saves entries on the ESP32, so this version does not need a microSD card.

900 note IDs

Browse IDs 0–899 in groups of 50 on the web interface. Real capacity depends on available flash space and entry sizes.

Physical controls

Three buttons provide note browsing, reading, page navigation, and delete confirmation on the TFT.

Quick start

  1. Install esp32 by Espressif Systems 3.3.3 in Arduino IDE.
  2. Install Adafruit GFX Library and Adafruit ST7735 and ST7789 Library.
  3. Open the sketch, select the correct ESP32 board and a partition scheme with a compatible filesystem partition, then compile and upload.
  4. Open Serial Monitor at 115200 baud. Confirm LittleFS mounts successfully.
  5. Connect to Wi-Fi ESP32-Diary, password 12345678, and visit http://192.168.4.1.

Storage warning: If LittleFS fails to mount, the sketch does not automatically format it. Check the partition setup first. A deliberate format erases saved notes.

Project notes

  • Title limit: 48 characters.
  • Body limit: 800 characters.
  • The TFT caches the newest 10 notes in RAM to reduce memory use.
  • 900 IDs are available in the file naming scheme, but 900 long notes may not fit in flash.
  • This project targets ESP32 Arduino core 3.3.3; compile and test on your own hardware before relying on it.
